# DIYCraft — Peaceful Voxel World

Open the game at the GitHub Pages `/offline/` route. It is a self-contained offline-capable HTML game with no third-party scripts or external gameplay requests.

- Drag the world to look around; tap to place a block.
- Use the left movement pad and right build/remove/flight controls on touch screens.
- Switch between first-person and third-person views.
- Toggle creative flight and rise/descend while flying.
- Hide controllers or use Enlarge for a focused view.
- Choose from the hotbar or select any custom block color in the menu.
- Resource and crafted pouches each have 60 slots.
- Save is local to the device; use Backup world / Restore backup to keep or transfer a world.

Creative blocks do not consume resources. A technical cap of 18,000 placed blocks protects device performance. This is an original peaceful voxel-style prototype, not Minecraft and not affiliated with Mojang or Microsoft.
